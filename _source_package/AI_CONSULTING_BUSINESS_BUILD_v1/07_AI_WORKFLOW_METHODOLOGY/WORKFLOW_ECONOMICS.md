# Workflow Economics

**Purpose:** Choose automation depth rationally

**Version:** 1.0 | **Date:** 2026-08-28

## Total cost

Discovery + implementation + client time + licenses + usage + integration + security/legal + training + monitoring + maintenance + expected failure/rework + switching cost.

## Value

Hard expenditure reduction + probability-weighted contribution from revenue + value of redeployed capacity + expected loss reduction + quality/service value. Report each separately.

## Complexity bands

Low: manual prompt/template, no integration. Medium: knowledge sources, structured output, one integration, human approval. High: multiple systems/models, sensitive data, external actions, complex exceptions. Complexity drives testing, controls, and price.

## Build gate

Proceed when the workflow is repeated, evidence can be tested, owner exists, data is authorized, benefit exceeds total cost under a conservative case, and safe fallback exists.
