# Cheat Sheets and Guides

**Purpose:** Support daily use and workflow building

**Version:** 1.0 | **Date:** 2026-08-28

## Before using AI

Confirm approved tool/account; classify data; minimize content; use current source; know required reviewer; do not paste credentials or restricted data.

## Instruction pattern

Role/context → objective → approved sources → required steps → constraints → output schema → verification → uncertainty/escalation. Store versions centrally.

## Troubleshooting

Wrong output: check input/source/version; do not repeatedly rephrase around a control. Missing context: stop and request it. Tool outage: use documented fallback. Suspected exposure: stop, preserve evidence, notify security contact. Integration duplicate: do not retry blindly; check idempotency/status.

## Change guide

Describe desired outcome; update map/risks; create test cases; compare candidates; obtain approval; version instructions/config; deploy in controlled environment; monitor; preserve rollback.
