# EchoFrame — Brand Kit (paste this into any new chat before asking for designs)

Use these EXACT values. Do not invent new colors, fonts, or styles. If something
isn't specified here, choose the simplest option that fits — do not add decoration.

## Colors (use these hex codes only)
- Navy (primary background / headlines): #0a274f  (alt deep slate: #0f172a)
- Gold (accent — use sparingly for "$25", CTA buttons, key highlights): #c9973d
- Gold dark (hover/borders): #a67c2e
- Cream (soft background): #fdf3e3
- White: #ffffff
- Text dark: #111827
- Text medium: #4b5563
- Text muted: #6b7280
- Light line/border: #e5e7eb

**Rule:** Navy and white/cream do the heavy lifting. Gold is the ONLY accent —
use it on one thing per design (the payout or the CTA), never everywhere.

## Typography
- Font: Inter (fallback: -apple-system, Segoe UI, Roboto, Arial, sans-serif)
- Headlines: Inter Bold / Extrabold
- Body: Inter Regular
- One font only. No script, no display fonts, no mixing.

## Logo
- Use "EchoFrame Logo.png" (in this folder). On navy backgrounds use the
  light/white logo; on white/cream use the navy logo.
- Always leave clear space around it. Never stretch, recolor, or add effects.

## Layout rules (keep it consistent)
- Generous whitespace. Clean, financial, trustworthy — not busy.
- One headline, one supporting line, one CTA. Don't crowd.
- Rounded corners (~8–12px), subtle shadows only. No gradients unless navy→deep-navy.
- Square (1080×1080) or vertical (1080×1350) for Instagram feed; 1080×1920 for Stories.

## Voice (so text on graphics matches)
- Plain English, confident, calm. Short sentences.
- Hero promise: "EchoFrame reads your business's money and tells you, in plain
  English, what's going on — and the #1 thing to fix to keep more of it."
