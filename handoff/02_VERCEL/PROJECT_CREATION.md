## Create

## Settings

Project name `white-oak-operations`; Framework Next.js; Root Directory `website`; Production branch `main`; detected install/build/output defaults unless inspected repo requires otherwise.

## Safety

Do not connect IONOS or permanent domain. Do not use live Stripe. Do not deploy `website-implementation` as Production. Initial main deployment may be incomplete before variables; document outcome.

## Alternative

If owner prefers connector deployment, grant the connected identity Owner/Member or Developer with Create Project extended permission. Manual import remains preferred.
