# EchoFrame — Sample Deliverable Generation Prompts

One prompt per product (Clarity Report excluded — you already have that sample).
Paste a prompt into Claude to generate a one-page sample. Each is styled to match
your Lumière Clarity Report: navy (#0A274F) header band, amber (#94681C) accents,
Inter font, KPI cards up top, "POWERED BY EchoFrame", tagline "Business
intelligence, not accounting.", and a "Page 1 of X · Confidential" footer.
Every sample uses a realistic but FICTIONAL Columbus, GA business and is clearly
marked as a redacted sample. Each ends with "The One Thing" — a single
recommendation tied to a specific dollar amount.

Create a one-page sample **Auto Ledger** report for EchoFrame, styled like our Clarity Report sample (navy header band, amber accents, Inter font, KPI cards, "POWERED BY EchoFrame", tagline "Business intelligence, not accounting.", "Page 1 of 4 · Confidential" footer).
