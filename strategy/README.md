# Read Me First

**Purpose:** Orient Claude Code or a human operator to this implementation-ready business package

**Version:** 1.0 | **Date:** 2026-08-28

## What this is

A complete v1 operating system for a vendor-neutral AI workflow consulting, implementation, and education company serving established businesses, initially in New York. It includes commercial decisions, client delivery templates, governance, training, financial models, website starter source, Stripe specifications, and a local implementation handoff.

## Working identity

**White Oak Operations is the selected working company name, pending
trademark, entity-name, domain, and common-law clearance** (see
`strategy/DECISION_LOG.md`). "Practical AI Operations" was the prior
placeholder working label used while the package was implemented; it has
been replaced with White Oak Operations throughout the website and
operational docs. Do not treat this as a final, cleared brand — complete
all four clearances before public launch.

## Safety boundary

Legal drafts require attorney review. Security guidance is a baseline, not a certification. Client data must not enter an AI tool until classification, authorization, retention, and vendor settings are confirmed. Human review is mandatory for consequential outputs.

## Artifact map

Markdown is authoritative for editable policy and operating content. DOCX/PDF versions are client-facing renderings. XLSX files contain formulas and scenarios. JSON/CSV files are machine-readable inputs. Website starter files are illustrative source for Claude to integrate, test, and deploy.
