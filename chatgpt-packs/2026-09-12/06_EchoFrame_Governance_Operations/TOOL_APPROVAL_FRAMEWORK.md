# EchoFrame Tool Approval Framework

Evaluate a tool against:

## Business Fit
- solves defined workflow
- existing client tool cannot solve it adequately
- cost justified

## Technical Fit
- API/export capability
- reliability
- permissions
- logging
- error handling
- portability

## Data Fit
- data categories supported
- retention
- training use
- region/storage requirements
- deletion

## Security
- MFA
- role-based access
- audit logs
- vendor security documentation
- incident response information

## Operational Fit
- client can own account
- client can maintain it
- no unnecessary EchoFrame lock-in
- vendor dependency understood

## AI-Specific
- model behavior appropriate to task
- structured output support if needed
- evaluation method
- fallback
- human review

## Decision
Approved  
Approved with conditions  
Pilot only  
Rejected
