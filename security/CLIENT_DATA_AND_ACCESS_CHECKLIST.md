# Client Data & Access Checklist

## Before Access
- client authorization documented
- account owner identified
- least-privilege role selected
- individual login preferred
- MFA enabled where available
- shared-password workaround avoided

## Data Classification
Mark data as:
- ordinary business
- confidential
- financial
- PII
- PHI
- employee
- legal/privileged
- payment/card
- other regulated

## AI Use
For any data sent to an AI vendor:
- vendor identified
- purpose documented
- client approved
- retention/training terms checked
- unnecessary fields removed
- sensitive categories gated

## Storage
- location
- owner
- retention
- deletion process
- backups
- export/handoff

## Offboarding
- remove EchoFrame access
- rotate credentials if needed
- transfer client-owned artifacts
- delete retained data according to agreement
- document completion
