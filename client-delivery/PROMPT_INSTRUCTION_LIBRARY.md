# Prompt Instruction Library

**Purpose:** Provide a polished client-deliverable structure

**Version:** 1.0 | **Date:** 2026-08-28

## Executive standard

Lead with the business decision and verified evidence. Mark estimates. Remove internal notes. Use the client’s terminology and accessibility needs.

## Required sections

- ID
- workflow
- owner
- version
- approved model/config
- instruction
- variables
- examples
- prohibited content
- expected schema
- tests
- change approval.

## Quality gate

Factual owner review; security/data review; internal consistency; accessible headings/tables; no confidential data beyond authorized audience; decisions, limits, and next actions explicit.
