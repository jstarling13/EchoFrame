# EchoFrame Change Control

## Why
Hourly work can still become unbounded if every new request is treated as part of the original scope.

## A Change Is Material When
- another entity/location is added
- another workflow is added
- a new integration is required
- source system changes
- data is materially different from what was described
- new security/compliance requirements appear
- new reports/dashboards are requested
- client asks for functionality outside acceptance criteria

## Process
1. Describe requested change.
2. Explain why it is outside the current scope.
3. Estimate added effort/range.
4. Identify new access or risks.
5. Obtain written approval.
6. Add to current work or schedule as a later phase.

## Client-Friendly Language
"That makes sense as an addition. It wasn't included in the current scope, so I'll separate it, estimate the extra hours, and let you decide whether to add it now or leave it for later."
