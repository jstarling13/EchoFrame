# Acceptance Criteria

**Purpose:** Define release gates

**Version:** 1.0 | **Date:** 2026-08-28

## Content

All required pages and legal links; copy matches approved package; permanent business facts resolved; no accidental placeholders; claims are supportable.

## Experience

Responsive, keyboard complete, readable, WCAG 2.2 AA target, clear errors/success, fast representative mobile experience.

## Security/privacy

No secrets/client-side keys except publishable key; data-minimized forms; consent and privacy match implementation; headers, logs, access, retention, incident route documented.

## Payments

Test objects match catalog; milestones handled by invoices; O5 subscription lifecycle works; webhook idempotency/signature verified; reconciliation by project ID; refund/cancel behavior matches policy.

## Operations

CRM lead arrives; notifications work; project can be created; documents accessible; backup/rollback/offboarding steps tested.

## Deployment

Git clean and reviewed; tests pass; Preview approved; correct Vercel project; exact DNS plan; mail records preserved; SSL and redirects valid; production owner approval recorded.
