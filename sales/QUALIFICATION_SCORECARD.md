# EchoFrame Qualification Scorecard

Score 0–2 in each category.

## 1. Pain Is Real
0 = vague curiosity  
1 = some friction  
2 = recurring measurable problem

## 2. Sponsor
0 = no decision-maker  
1 = influencer only  
2 = owner/executive sponsor engaged

## 3. Process Owner
0 = no one owns workflow  
1 = partial ownership  
2 = clear subject-matter owner

## 4. Frequency
0 = rare  
1 = periodic  
2 = frequent/recurring

## 5. Economics
0 = no meaningful cost/value  
1 = uncertain  
2 = meaningful labor/risk/capacity value

## 6. Systems / Data Access
0 = blocked  
1 = uncertain  
2 = feasible access

## 7. Process Stability
0 = process changes constantly  
1 = partially stable  
2 = stable enough to automate

## 8. Risk
0 = unsupported high-risk use  
1 = manageable with controls  
2 = low/moderate risk

## 9. Client Cooperation
0 = wants magic / no involvement  
1 = uncertain  
2 = willing to map, test, and approve

## 10. Support Fit
0 = likely 24/7 or indefinite burden  
1 = moderate  
2 = bounded / transferable

## Interpretation
16–20: strong fit  
11–15: investigate / narrow scope  
0–10: likely decline or redirect

Risk veto:
A high-risk unsupported workflow can be declined regardless of total score.
