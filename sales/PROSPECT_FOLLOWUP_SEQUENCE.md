# EchoFrame Prospect Follow-Up Sequence

## Day 0 — Scope / Proposal Sent
Send proposal and identify one clear next action.

## Day 2–3 — Confirmation
"Just wanted to make sure you received the scope. If anything in it doesn't match the workflow we discussed, tell me and I'll correct it."

## Day 7 — Decision Follow-Up
"Checking in on the proposal. The main question is whether [workflow] is important enough to address now. If timing isn't right, no problem. If you want to move forward, I can confirm the next available start window."

## Day 14 — Close the Loop
"I wanted to close the loop rather than keep following up. If you want to revisit the project later, the scope gives us a starting point. If the process has changed by then, we'll re-check the assumptions before doing any work."

## Rules
- no daily chasing
- no fake urgency
- no discounting simply to force a close
- re-scope if the client's process materially changes
