# EchoFrame Service Selection Matrix

| Client Signal | Likely Starting Service | Follow-On |
|---|---|---|
| "I know we waste time but don't know where" | Workflow Discovery & Opportunity Mapping | Process Automation |
| Bookkeeper buried in matching/reconciliation | Financial Workflow Automation | Reporting / Multi-Entity |
| Multiple businesses / tax IDs | Multi-Entity & Intercompany Tracking | Owner Dashboard |
| Too much email/manual intake | Process & Workflow Automation | Reporting |
| Leads go cold | Customer Communication & Lead Follow-Up | Pipeline Reporting |
| Owner manually builds weekly/monthly report | Reporting & Owner Dashboards | Data workflow cleanup |
| Staff using ChatGPT inconsistently | Staff Training + Systems/AI Review | Internal assistants |
| Existing automation keeps breaking | Ongoing AI Consulting | System redesign if needed |
| Sensitive workflow / unclear access | Systems & Security Review | Controlled implementation |
| Complex workflow with uncertain ROI | Paid Diagnostic | Scoped implementation |
