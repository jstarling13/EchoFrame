# Internal Operating Manual

**Purpose:** Run the practice consistently

**Version:** 1.0 | **Date:** 2026-08-28

## Weekly rhythm

Monday pipeline/capacity/risk; daily client next actions; Friday delivery QA, billing, documentation, backups, and metrics. Monthly finance/security/vendor review. Quarterly offer and policy review.

## Project lifecycle

Qualify → contract/deposit → intake → data gate → discovery → design → acceptance plan → build → test → train → launch → stabilize → measure → handoff → offboard/retainer.

## Documentation

One source of truth per project; dated decisions; versioned instructions/config; evidence links, not duplicated sensitive data; meeting notes with owner/action/date; no credentials in documents.

## Quality

No deliverable leaves without factual review, consistency check, risk/data review, and client decision/next action. Production changes require approval, backup/rollback, and evidence.

## Capacity

Sell against realistic founder hours. Protect design/test time. Use contractors only under NDA/data/access controls and disclose where required.
