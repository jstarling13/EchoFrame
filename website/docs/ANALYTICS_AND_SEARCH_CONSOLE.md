# Analytics & Search Console Setup

## Principle
Collect enough data to improve the site without adding unnecessary tracking.

## Minimum Events
- page view
- contact CTA click
- contact form start
- contact form submit
- service-card click
- industry-selector selection
- industry-selector completion
- outbound email/phone click if applicable

## Do Not Track Sensitive Form Content
Analytics should not receive free-text inquiry details, financial information, health information, credentials, or client documents.

## Conversion Definition
Primary: qualified contact submission.

Secondary:
- click into services
- complete industry selector
- referral landing-page visit
- contact action

## Search Console
Once canonical domain is live:
- verify ownership
- submit sitemap
- inspect homepage/services/industries URLs
- monitor indexing
- monitor branded queries
- monitor crawl errors

## Privacy
Before enabling analytics/cookies:
- update actual privacy disclosure
- confirm tool and configuration
- determine whether consent is required for intended audience/jurisdictions
