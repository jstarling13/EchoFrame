# EchoFrame SEO / Technical Launch Checklist

## Crawl / Index
- [ ] production pages return 200
- [ ] no accidental `noindex`
- [ ] `robots.txt` exists
- [ ] robots allows public marketing pages
- [ ] private/internal/API routes not exposed unnecessarily
- [ ] sitemap exists
- [ ] sitemap uses canonical production domain
- [ ] sitemap excludes obsolete/unlinked package routes if they should not rank
- [ ] canonical URLs correct
- [ ] old White Oak / obsolete URLs redirect or remain intentionally non-indexed

## Metadata
- [ ] unique title each main page
- [ ] unique meta description each main page
- [ ] metadataBase uses canonical domain
- [ ] Open Graph title/description/image
- [ ] social preview verified
- [ ] favicon / app icons
- [ ] no stale business name
- [ ] no old fixed-package pricing in meta text

## Page Structure
- [ ] exactly one clear H1 per page
- [ ] logical heading hierarchy
- [ ] descriptive anchor text
- [ ] image alt text
- [ ] industry selector is keyboard accessible once Pack 11 is implemented

## Content
- [ ] homepage clearly states AI implementation/workflow automation
- [ ] service page matches current hourly model
- [ ] industries reflect adopted two-lane ICP
- [ ] location language is accurate, not spammy
- [ ] bookkeeper/CPA assist-not-replace language retained
- [ ] legal pages finalized only after professional review

## Technical
- [ ] HTTPS
- [ ] no mixed content
- [ ] no broken links
- [ ] 404 works
- [ ] redirects intentional
- [ ] mobile responsive
- [ ] Lighthouse/Core Web Vitals checked
- [ ] large images optimized
- [ ] unused assets not loaded on home
- [ ] production console clean of avoidable errors

## Search Engine Setup
- [ ] Google Search Console property added
- [ ] domain ownership verified
- [ ] sitemap submitted
- [ ] Bing Webmaster Tools considered
- [ ] branded search checked after indexing

## Local / Referral Credibility
If serving a real local/regional market:
- [ ] consistent business name/contact
- [ ] accurate service area
- [ ] do not create fake offices/addresses
