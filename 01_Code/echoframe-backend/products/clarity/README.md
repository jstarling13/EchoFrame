# Monthly Clarity Report

- **Engine:** `clarity_engine.py`
- **Template:** native `.docx` (python-docx, no Jinja template)

## Documents the customer provides

Your file should be a monthly P&L that includes:
- Total revenue / sales for the month
- Each expense line item with its amount
- Prior-month figures too, if you have them (sharpens the trends)

**Where to export from:** Your accounting tool (QuickBooks, Xero, Wave) can export a Profit & Loss statement to CSV.
