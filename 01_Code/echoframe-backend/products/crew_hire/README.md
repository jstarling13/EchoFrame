# Crew Hire

- **Engine:** `crew_hire_engine.py`
- **Template:** `crew_hire.html.j2`

## Documents the customer provides

Your file should include one row per applicant, with:
- The role you're hiring for and any must-have requirements
- Applicant name
- Their screening scores / how they stack up on your must-haves
- Current status (new, screened, interviewing, etc.)

**Where to export from:** Export applicants from your job board or ATS (Indeed, ZipRecruiter, etc.) to CSV, with any screening notes you've added.
