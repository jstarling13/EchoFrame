# Permit Watch

- **Engine:** `permit_watch_engine.py`
- **Template:** `permit_watch.html.j2`

## Documents the customer provides

Your file should include one row per license, permit, or fleet item, with:
- What the item is (license, tag, inspection, insurance, etc.)
- Entity or vehicle it belongs to
- Expiration / renewal date

**Where to export from:** List your business licenses, vehicle registrations, certifications, and insurance renewals in a spreadsheet, then export to CSV.
