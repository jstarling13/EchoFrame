# Drive Pay

- **Engine:** `drive_pay_engine.py`
- **Template:** `drive_pay.html.j2`

## Documents the customer provides

Your file should include one row per closed repair order, with:
- Date & time the repair order closed
- Customer name
- Vehicle - year, make & model
- Invoice total ($)
- Payment outcome - paid at pickup, paid later, or unpaid
- Time from pay-link sent to payment cleared (if available)

**Where to export from:** Most shop-management systems (Tekmetric, Shop-Ware, Mitchell 1, etc.) can export closed repair orders with payment status to CSV.
