# Quote Revive

- **Engine:** `quote_revive_engine.py`
- **Template:** `quote_revive.html.j2`

## Documents the customer provides

Your file should include one row per open quote, with:
- Quote / estimate ID
- Job description
- Quote value ($)
- Date the quote was sent
- Number of follow-ups already sent
- Current status (open, won, lost)

**Where to export from:** Your quoting or CRM tool (Jobber, ServiceTitan, Housecall Pro, etc.) can export open estimates to CSV.
