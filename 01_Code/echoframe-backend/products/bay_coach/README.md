# Bay Coach

- **Engine:** `bay_coach_engine.py`
- **Template:** `bay_coach.html.j2`

## Documents the customer provides

Your file should include, per vehicle:
- Vehicle - year, make & model
- Current mileage / odometer
- Past services with their dates
- Your shop's pricing for the services you offer

**Where to export from:** Your shop-management system / DMS (Tekmetric, Mitchell 1, Shop-Ware, etc.) exports vehicle service history to CSV.
