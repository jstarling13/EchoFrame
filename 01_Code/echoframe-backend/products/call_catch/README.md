# Call Catch

- **Engine:** `call_catch_engine.py`
- **Template:** `call_catch.html.j2`

## Documents the customer provides

Your file should include one row per missed call, with:
- Time of the call
- Caller (name or number)
- Auto-text that was sent back
- Whether the caller replied
- Outcome - booked job & its value ($), if any

**Where to export from:** Most VoIP / business-phone systems (OpenPhone, RingCentral, Dialpad) export call logs with text history to CSV.
